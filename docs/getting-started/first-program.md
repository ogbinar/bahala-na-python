## Quick Verification

Let's do a quick sanity check that Python is working correctly.

### Step 1: Test the Interpreter

Open your terminal and type:

```bash
python3
```

You should see the Python prompt:

```pycon
>>>
```

Type this and press Enter:

```pycon
>>> print("Kumusta!")
```

You should see:

```
Kumusta!
```

Type `exit()` to leave the interpreter.

### Step 2: Test a Python File

Create a file called `hello.py` and type:

```python
print("Hello, World!")
print("Kaya ko 'to!")
```

Save it, then run it:

```bash
python3 hello.py
```

You should see:

```
Hello, World!
Kaya ko 'to!
```

### You're Ready

If both steps worked, Python is set up correctly. You're ready to start learning properly.
