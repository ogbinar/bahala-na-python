# Getting Started

> Before we write any code, let's make sure you have everything set up.

---

## What You'll Need

You don't need much:

- **A computer** -- Any computer. Even a 2GB RAM laptop works.
- **Internet access** -- For downloading Python and reading along. WiFi hunting is fine.
- **Curiosity** -- The most important tool.
- **Patience** -- This is a marathon, not a sprint.

## What You'll Learn

- How to install Python on your computer
- How to use the Python interactive interpreter
- How to create and run your first Python file
- What to do when things go wrong (spoiler: they will)

## Alternative: No Installation Needed

If you don't want to install anything right now, or if you're on a school computer with restrictions, you can use one of these:

| Platform | URL | Best For |
|----------|-----|----------|
| Google Colab | https://colab.research.google.com | Full Python environment in browser |
| Replit | https://replit.com/languages/python3 | Quick experiments, save to cloud |
| Python.org online | https://python.org | Just the interpreter, nothing else |

These work on any device with a browser. But for the full experience, we recommend installing Python locally.
