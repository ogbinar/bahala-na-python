# Preface: Why This Book Exists

## Who This Book Is For

This book is for you if:

- You're a Filipino student who wants to learn Python but finds existing textbooks boring and too American
- You're a career shifter looking to break into tech without a CS degree
- You're an OFW's kid who's already tech-savvy and wants to build something real
- You're a small business owner (sari-sari store, carinderia, online seller) who wants to automate your work
- You're just curious and want to see if you can code

This book is **not** for you if:

- You're looking for a comprehensive Python reference (that's what the official docs are for)
- You want academic, textbook-style explanations (we speak Taglish here)
- You think you need to be "good at math" to code (you don't)

## How to Use This Book

### Read It Linearly

Start from Chapter 1 and go in order. Each chapter builds on the previous one. It's okay to skip a Side Quest, but don't skip the Boss Fights.

### Build Along

Don't just read. Type the code. Run it. Break it. Fix it. That's how you learn.

### Use the XP System

Track your progress using the XP tracker in the bottom-right corner. Earn XP by reading chapters, completing exercises, and beating Boss Fights. Level up from Tambay to Legend!

### Join the Community

Learning alone is hard. Join our [Discord server](https://discord.gg/bahala-na-python) to get help, share projects, and celebrate wins with your barkada.

## About the Smart Kuya

I'm not a professor. I'm not a tech bro. I'm the big sibling who's been through this -- the confusion, the frustration, the "hindi ako para dito" moments. And I made it out the other side.

I learned Python in a comshop, drinking instant coffee, with a P30 night rate. My first program was a calculator for my Lola's sari-sari store. My second was a budget tracker for my allowance. My third was a Discord bot for my barkada.

That's what this book is. Not a textbook. A story. Your story.

**Bahala na. Let's try it.**
