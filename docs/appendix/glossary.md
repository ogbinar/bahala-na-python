## A

**API (Application Programming Interface)** -- A way for programs to communicate with each other. Like a restaurant menu: you order what's available, the kitchen prepares it, and you get your food.

**Async (Asynchronous Programming)** -- Writing code that can handle multiple tasks at once without waiting. Like a waiter taking orders from multiple tables instead of standing at one.

## B

**Bahala Na** -- A Filipino philosophy meaning "do your best, try it, see what happens, fix it later." Not fatalism -- courage in the face of uncertainty.

**Bayanihan** -- The Filipino tradition of community cooperation. Neighbors lifting a bahay kubo together. In tech: open-source collaboration.

**Boolean** -- A data type that can be either `True` or `False`. Like a light switch: on or off.

## C

**Class** -- A blueprint for creating objects. Like a cookie cutter: the class is the cutter, the objects are the cookies.

**CLI (Command Line Interface)** -- A text-based interface where you type commands. Also called "terminal" or "command prompt."

**Code** -- Instructions written in a programming language that tell a computer what to do.

**Commit** -- Saving a snapshot of your changes in Git. Like saving a game.

**Constructor** -- A special method (`__init__`) that runs when you create a new object. Sets up the object's initial state.

## D

**Data Type** -- The category of data: string (text), integer (whole number), float (decimal), boolean (True/False).

**Dictionary** -- A data structure that stores key-value pairs. Like a real dictionary: look up a word (key) and get its definition (value).

**Diskarte** -- Filipino resourcefulness. Making do with what you have. In programming: finding a solution, even if it's not perfect.

**DOM (Document Object Model)** -- The structure of a web page as a tree of objects. JavaScript can modify the DOM to change what you see.

## E

**Error** -- A problem in your code that prevents it from running. Also called a "bug" (though bugs are usually logical errors, not syntax errors).

**Exception** -- An error that happens while the program is running. Python handles exceptions with `try/except`.

## F

**Flask** -- A lightweight Python web framework. Used to create web APIs and websites with minimal code.

**Float** -- A data type for decimal numbers. `3.14` is a float. `3` is an integer.

**Function** -- A reusable block of code that performs a specific task. Like a recipe: you give it ingredients (inputs) and it gives you a result (output).

## G

**Git** -- A version control system that tracks changes to your code. Like a time machine for your files.

**GUI (Graphical User Interface)** -- A visual interface with buttons, menus, and windows. The opposite of CLI.

## I

**asyncio** -- Python's library for writing concurrent code using `async`/`await`. Lets you do multiple things at once, like handling many Discord bot messages simultaneously.

**IDE (Integrated Development Environment)** -- A program that helps you write code. Examples: VS Code, PyCharm, Sublime Text.

**Import** -- Bringing code from another file or library into your program. Like borrowing a tool from a friend.

**Index** -- The position of an item in a list. Python starts counting at 0, so the first item is at index 0.

**Inheritance** -- A class that builds on another class. Like a child inheriting traits from a parent.

## K

**Kivy** -- A Python framework for building cross-platform mobile and desktop apps with a natural touch interface. Used for Android (via Buildozer) and desktop apps.

**Kaya mo yan** -- "You can do it!" The universal Filipino encouragement.

## L

**Library** -- A collection of pre-written code that you can use in your programs. Like a toolbox.

**List** -- An ordered collection of items. Like a shopping list: items are in a specific order, and you can add, remove, or rearrange them.

## M

**Method** -- A function that belongs to a class. Like a verb for a noun: the object (noun) performs the action (verb/method).

**NLP (Natural Language Processing)** -- Teaching computers to understand human language. Includes tasks like sentiment analysis, translation, and chatbot responses.

## O

**Object** -- An instance of a class. If the class is a blueprint, the object is the house built from it.

**OOP (Object-Oriented Programming)** -- A programming paradigm where code is organized around objects and classes.

## P

**Package** -- A collection of Python libraries. Installed with `pip`.

**pandas** -- A Python library for data analysis. Think of it as Excel in Python: you can read, filter, group, and visualize data using code.

**Parameter** -- A variable in a function definition. The "slot" where data goes in.

**PATH** -- A system variable that tells your computer where to find programs. Like a directory of all the apps you can run from the command line.

**pip** -- Python's package installer. Used to install libraries: `pip install requests`.

## R

**Repository (Repo)** -- A project's folder in Git/GitHub. Contains all the files and the full history of changes.

## S

**String** -- A sequence of text characters. Written with quotes: `"hello"` or `'hello'`.

**Syntax** -- The rules of a programming language. Like grammar in English: wrong syntax means the computer can't understand your code.

## T

**Termux** -- A terminal emulator for Android that lets you run Python and other tools directly on your phone. Great for coding on low-end devices without desktop access.

**Terminal** -- A program where you type commands to interact with your computer. Also called "command prompt" (Windows) or "shell."

**Tokenization** -- Breaking text into individual words or tokens. The first step in NLP: "Kumusta ka?" becomes ["Kumusta", "ka"].

**Type** -- See "Data Type."

## V

**Variable** -- A labeled container for data. Like a box with a name tag.

**Virtual Environment** -- An isolated Python environment. Packages installed here don't affect other projects.

**Vibecoding** -- A term popularized by Andrej Karpathy (2024). The flow state of coding with AI: you describe what you want in natural language, and AI generates the code. "You vibe, it codes."

## W

**Web Scraping** -- Writing code to automatically extract data from websites. Like a robot reading web pages for you.
